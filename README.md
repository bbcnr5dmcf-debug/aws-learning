# aws-learning#

## 学習済み
### S3
- 静的Webサイトホスティングの設定

### EC2
- キーペアの作成と設定
- ネットワーク設定（セキュリティグループなど）

### AWS Budgets
- 予算の閾値設定
- メール通知の連携
